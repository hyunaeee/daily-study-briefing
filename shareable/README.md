# 매일 학습 브리핑 — 배포용 템플릿

다른 사람들도 쓸 수 있는 버전. **온보딩**에서 닉네임 · 관심 분야(CS/마케팅/AI/디자인) · 수준 · 하루 학습 시간을 수집하고, 그 프로필에 맞춰 콘텐츠를 필터링합니다.

## 데모 실행

```
node server.js
```

→ http://localhost:4174 접속. 첫 방문이면 온보딩이 뜨고, 프로필은 브라우저 localStorage(`dsb.profile`)에 저장됩니다. 헤더의 "⚙ 관심 분야 다시 설정"으로 언제든 다시 할 수 있습니다.

## 온보딩이 수집하는 데이터

| 항목 | 값 | 현재 반영 |
|---|---|---|
| 닉네임 | 자유 입력 | 헤더 인사말 |
| 관심 분야 | cs / mkt / ai / dsg 다중 선택 | 개념 카드·아카이브 필터링 |
| 수준 | 입문 / 중급 / 심화 | 표시만 (서버 버전에서 콘텐츠 생성에 반영 예정) |
| 하루 학습 시간 | 15 / 30 / 60분 | 15분이면 딥다이브·퀴즈 축소 |

## 개인용 버전과의 차이

- `personal/`: 나 혼자 쓰는 버전. 분야 고정(CS·마케팅·AI), 온보딩 없음, 로컬 Claude CLI가 매일 데이터 생성.
- `shareable/`: 이 폴더. 온보딩 + 프로필 기반 필터링. 데이터는 아직 정적 샘플(day-001).

## 나중에 서버 배포할 때 할 일 (로드맵)

1. **프로필 저장을 서버로**: `js/onboarding.js`의 `finish()`에서 localStorage 대신 `POST /api/profile` 호출로 교체. 계정 개념이 필요하면 이메일 매직링크 정도로 가볍게 시작.
2. **콘텐츠 생성 파이프라인**: `personal/update/update-prompt.md`와 같은 방식의 일일 생성 작업을 서버 크론으로 옮기고, 분야별(cs/mkt/ai/dsg/…)로 하루치 JSON을 전 분야 생성 → 사용자별로는 프로필에 맞춰 골라서 서빙. 사용자 수와 무관하게 생성 비용은 하루 1회 고정.
3. **수준(level) 반영**: 분야별 콘텐츠를 입문/심화 두 버전으로 생성하거나, deepDive 섹션에 난이도 태그를 달아 필터링.
4. **호스팅**: 정적 파일 + JSON이라 Vercel/Netlify/Cloudflare Pages면 충분. 생성 작업만 GitHub Actions 크론이나 작은 서버에 두면 됨.
5. **진도 저장**: 퀴즈 결과·완료 체크를 프로필에 누적하면 리텐션 장치(연속 학습 스트릭)가 됩니다.
